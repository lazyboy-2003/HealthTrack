# HealthTrack

A privacy-first, gym-inspired Flutter health tracker.

## Full-version roadmap in progress
- Blood pressure manual logging + history
- Camera + flash pulse estimate
- Automatic step counter
- Water, stress, weight and sleep tracking
- Daily goals and motivational launch experience
- Weekly/monthly charts
- Local-first records
- Health Connect integration
- Reminders
- PIN / biometric privacy
- Export and backup

## Safety
Camera pulse is a wellness estimate, not a medical device. Blood pressure is never inferred from the phone camera.

## Build
Flutter 3.x / Dart 3.x. Run `flutter pub get`, then `flutter run`.
